Download dataset

One zip: your clips trimmed, loudness-normalized and resampled to 24 kHz, a manifest.jsonl with the text of each clip, and finetune.py. Preparing takes up to a minute for thirty minutes of audio. The name goes into the prompt Perform TTS. Use …'s voice., which is what the fine-tune teaches the model to honor.

Train on your own GPU

  1. Get a CUDA machine.

    A full fine-tune of the 1.5B model wants about 40 GB of GPU memory at batch 16. An A100-80GB or H100 on any cloud is comfortable; a 24 GB card works with --batch 4. Ten minutes of audio is roughly ten minutes on an A100.

  2. Install and fetch the script.

    Python 3.12. The script and the zip are all you need.

    pip install "liquid-audio==1.3.0" soundfile
curl -O ORIGIN/finetune.py
  3. Unzip and train.

    Tokenizes your clips into Mimi audio tokens, fine-tunes with Liquid's Trainer for about 300 optimizer steps, then renders four sample sentences into ckpt/NAME/samples/.

    unzip voice-SLUG.zip
python finetune.py train --data voice-SLUG --name "NAME"
  4. Say anything.

    Renders a 24 kHz wav in your voice. Keep training_args.json next to final/ so the prompt is remembered.

    python finetune.py say --ckpt "ckpt/NAME/final" --text "Hey, this is NAME. It worked."

Sounds off? Record more (the recorder link keeps working; re-download), or add --epochs 20. Under ten minutes of audio the voice is recognisable but rough.
