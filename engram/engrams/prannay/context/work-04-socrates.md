Socrates is an ML agent Prannay built at Hexo with a Socratic critique-and-revision loop: the agent proposes, a critic interrogates, the agent revises, and only then does it run.

On the Statoil iceberg classification task it beat the baseline agent by 8.67 percent lower log loss and converged six times faster: 1 hour 46 minutes instead of 13 hours 53 minutes.

His read on why it works: most agent failures are not capability failures, they are the agent never being asked the obvious question before it commits.
