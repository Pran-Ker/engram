Writing code is the most reliable path to deterministic outcomes from AI. Everything else is probabilistic. If you want an agent to actually do the thing the same way twice, have it write the program and run the program. That's why I'm on post-training for coding and computer-use agents, and why program synthesis is my long bet for the decade.
